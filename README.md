# ⌨️ 鍵盤大陸：咒語打字冒險

一款用「打字施法打怪物」來練習英文打字的網頁小遊戲。單一 HTML 檔，不需安裝、不需建置，用瀏覽器開啟即可遊玩。

## 特色
- 五個主題關卡（字母、簡單單字、長單字、小句子、長句子），可自由選擇
- 練習工坊：自選內容、不扣血，含新手教學、數字與符號、弱點特訓
- 能力測驗：固定題目，可追蹤真實進步
- 準確率導向：三種難度、虛擬鍵盤與指法提示、弱點加權出題
- 分析頁：錯誤熱力圖、常混淆的鍵、反應最慢的鍵
- 收集：徽章、怪物圖鑑、傳說寶物、成就

## 遊玩前請注意
- 需要實體鍵盤
- 請切換成英文輸入法並關閉 Caps Lock
- 進度存在瀏覽器的 localStorage，換瀏覽器或清除資料會消失

## 本機執行
直接雙擊 `index.html` 即可。

## 如何擴充單字庫
打開 `index.html`，在檔案上方的 `W2`、`W3`、`SB`、`VB`、`OB` 等陣列加入 `["英文","中文"]` 即可。
